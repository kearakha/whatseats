# WhatSeats — Overview

## Tujuan
App untuk membantu user memilih menu makan malam secara random via spin wheel.

## Target User
Personal use, bisa dipakai di iOS maupun browser.

## Platform
- iOS (via Capacitor)
- Web (browser)

## Core Features
- Spin wheel dengan animasi smooth
- Tambah / hapus menu makan malam
- Hasil spin ditampilkan jelas setelah berhenti
- Data menu tersimpan per user (Supabase)
- Auth: login / register via Supabase
